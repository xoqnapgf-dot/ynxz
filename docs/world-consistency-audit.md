## 一、结论先说

**整体框架可以自洽，不需要为了统一“时代感”重写整站。** 立绘的古今未来混搭是站主确认的创作风格，不能拿衣服、王冠、建筑、发光图案或画面中的道具，直接推断国家科技、政治体制或人物职位。

这次最明确的文图落差是 **璇玑联邦的“西北沿海”表述**：当前国家边界是有湖岸、没有直接海岸的内陆区域。其余主要是**权源、制度层级、技术设施、改革时态和文档口径交代不足**，不是已经证明整个世界观有硬矛盾。

没有发现需要统一改掉全站人物出生年份的明确年龄—履历冲突。少数履历比较紧凑，建议补清学制或回归时间，而不是先凭印象把人物改老。

## 二、审查口径

### 应当分开的四个层次

1. **视觉风格**：可以古今未来混用；不直接证明装备已经能生产、人物实际拥有王位或国家处于某个现实年代。
2. **实际科技**：看正文里确实能运作的设备、生产体系和使用范围。专业部门、民用社会、偏远地区可以不在同一水平。
3. **政治制度**：区分名义国体、实际权力、中央与地方、正式职位和荣誉称号。
4. **人物立场**：反对派、改革者、理想主义者不需要和所在国的现行制度一致；人物自我辩解也不等于作者认定的客观事实。

只有**同一事实、同一时间、同一层级出现无法同时成立的明确叙述**，才算直接矛盾。资料没写清楚，先标“待澄清”；角色想建立某种制度，不等于国家已经实行它。

新历 540 年不是现实公元 540 年。不能据此要求所有人回到现实六世纪的技术或服饰。

## 三、优先处理的一处已验证文图落差

### G01 · 璇玑联邦：沿海介绍与内陆湖区边界

**证据**：
- `js/locations-data.js:2` 的“璇玑联邦”：写“在西大陆西北沿海”，由湖畔和港口城市组成。
- `README.md:28`：同样用“西北沿海”概括。
- `js/map-data.js:1`：该国为国家 ID 11。
- 国家底图及地图源文件的几何记录：ID 11 与奥嫩堡、卡法里扬、平、霁川接壤，有湖岸，没有邻接海洋的陆地单元。

**判断**：按通常的“本国临海”读法，这两种表述不一致。若“沿海”只是指更大的西北沿海经济区域，也需要说明本国没有直接海岸。**湖港、河港和通过邻国做外贸本身没有问题。**

**最小处理建议，二选一**：
- 保留地图：把介绍调整为“西北湖区／湖畔与河港城市联邦”，补一句对外运输经河道或邻国港口。这样不必迁移七位相关角色，也不必降低生命工学水平。
- 保留真正临海的设定：调整正式疆界或换位置，并同步底图及地理介绍；不能只挪一个标点就当作国家获得海岸。

这条影响地点介绍与世界观表述，**不要求改画像、人物名字或人物思想**。本次未代替站主选定方案。

## 四、需要补桥，而非直接判错的事项

### G02 · 特殊地点的主权与政治底图

**证据**：学院、群岛、天神峰是后来新增的独立／特殊地点标记。原国家色块仍覆盖其所在陆地：学院岛为 ID 5，常灵主岛为 ID 13，天神峰为 ID 14。

**同时成立的已知事实**：
- 学院在真正的海岛上；文字为中立自由学园，地点类型为独立地区。
- 常灵主岛也是海岛；文字没有明确指定其国家主权，不能自动认定它属于翁吉亚，也不能仅靠“特殊地点”类型自动认定独立。
- 天神峰明确写“不属于任何国家”，标点在东大陆高地，原色块仍划入卡斯奎尼亚区域。

**建议**：明确国家底图是否只是概览，以及特殊地点的飞地／无主区域是否以标记与地点志为准。若底图也要表达精确主权，应给学院区域、共奉山峰加例外边界或注释。

**不要做的事**：把学院人物改成布图里亚国民，把天神峰三位改归卡斯奎尼亚，或擅自给常灵群岛补上翁吉亚父级。原生成器的色块不能替作者决定这些问题。

### T01 · 铁枢的加密通信需要设备层说明

**证据**：
- 世界总览与铁枢介绍：近代工业背景，钢铁、铁路、票证及高度集中的计划。
- 尼克斯 `js/gallery-data.js:2537`：电讯监察署、自己写的通讯程序、各地节点、多开一台中继。
- 璇玑介绍已经允许技术授权和精密器件跨境交易。

**判断**：读者容易把“程序／节点”理解成现代计算机网络，但正文没有说明使用什么机器、如何供电、覆盖哪些人。不能反过来断言电报时代就不可能有加密、自动传输或网络：通信史资料中电报已有数字编码和自动纸带设备。[1](https://www.computerhistory.org/revolution/networking/19/406)

**建议**：选定机械／电报密码设备，或引进的近现代计算设备，并补清“专业部门先进、普通社会仍偏工业”的范围。她反监察、用户自建中继的立场不必改。

### P01 · 科鲁鲁的改革时态与“多党”口径

**证据**：
- 地点介绍仍是王座、教会、等级与旧俗并立。
- 索菲 `js/gallery-data.js:1583`：约新历 536 年登基，通过敕令编法、废刑讯、收回主教世俗权；法团院仍能提出异议。
- 法团两位、保守主义、功利主义、东方悦在同一国表达不同改革方向。
- README 一句话定位还使用“多党与法团政治”，正文没有写清政党如何组织、执政或制约王权。

**判断**：旧势力仍在、中央改革进行中、社会派别反对女王，都可以共存。未见“女王已完成民主改制”与“仍是专断王权”这样的直接冲突。需要明确的是哪些敕令已经落实、教会还保有哪些权力，以及“多党”指现代政党还是多派别。

**建议**：补清改革执行范围与阻力；若尚未设计政党机制，简介先用“多派别与法团政治”。不要为了东方悦的共和愿望把国家直接改成共和国。

### P02 · 埃莉诺签署法案的权源

**证据**：`js/gallery-data.js:1557`，身份是“王室成员”，正文说她是王室长女，日常却签署议会送来的法案。

**判断**：君主立宪强调宪法对王权的约束，不规定所有架空国家必须套用同一套王室授权方式。[2](https://www.britannica.com/dictionary/constitutional-monarchy) 这里的问题不是“长女绝不可能签署”，而是尚未解释她凭什么代行这项正式职权。

**建议**：由站主确定她是否代行君主职务、经宪法授权，或已经继位但基础信息未更新。只需一句权源说明，不能擅自加入君主去世／退位的大剧情。

费雯的“王后”是南岸乡社的荣誉称号，正文明确没有发令权，不与埃莉诺的王室身份构成争夺同一王位的矛盾。

### P03 · 学院的称谓与自愿教学边界

**证据**：
- 学院地点志：不设权威教职、课程由师生自治会社商定。
- 安娜琪 `js/gallery-data.js:2221`：不颁校规、不裁决，院长只是组织和张罗。
- 艾薇塔 `js/gallery-data.js:739`：明确没有正式院长制，但说安娜琪“管课程和自治会社”。
- 赫卡忒 `js/gallery-data.js:754`：读书会“读完不许讨论，只许交一页”。

**判断**：“院长／副院长”已经被解释成非正式分工，不能仅凭称号就判学院变成了等级制。读书会也可以有参与者认可的课堂安排。

**建议**：把“管”明确为协调、把读书会规则明确为可自愿参加或退出的约定。不要抹掉人物的性格，也不要把一场读书会的规矩写成全院强制校规。

### T02 · 赛拉的科研审批与监察边界

**证据**：`js/gallery-data.js:2549`，学部不批准人体试验，她去院外民营诊所招志愿者；监察挑不出数据造假，“只好”查设备来源。

**判断**：激进研究者违反或规避机构规则，可以是人物剧情，不是世界观自动失效。不过“研究院不批准”和“联邦法律禁止”是否相同，文本没有区分。真实数据、签免责书也不能在叙述上自动代替所有安全与合法性问题。

**建议**：交代审批是院内权限还是国家监管，监察能查哪些手续与受试者保护。可以保留她冒险与钻空子的性格，不必擅自写一场逮捕或扩大成全国丑闻。

### H01 · 三处紧凑履历，暂未发现确定年龄错误

| 人物 | 现有信息 | 可成立的读法 | 可补清的地方 |
|---|---|---|---|
| 尼克斯 | 新历 520 年；16 岁入学院；毕业后工作到第三年辞职 | 两年制学习，18 岁毕业，20 岁进入工作第三年即可辞职 | 学制与辞职时间；不应未经确认先改成 25 岁 |
| 玛格丽特·班克斯 | 新历 516 年；20 岁出行；随后“四五年” | 四年后约 540 年回城，可成立 | 若确定走了五年，应明确是约 541 年的叙述，或改成“这几年” |
| 亨丽埃塔·冯·莱茵 | 新历 510 年；抄写工作十二年后升任 | 青少年入署，十二年后升任，约 30 岁仍可成立 | 可补入署／升任年，不应默认所有人必须成年才开始工作 |

其他已检查的明确节点也能容纳：索菲 21 岁登基约为 536 年；埃莉诺 15 岁遇到宪法约为 527 年，之后六年学习／走乡社不超出约 540 年；卢西娅 28 岁领衔早于现在；维罗妮卡 25 岁任职早于现在。

斯凯“筹票两年”与“议案从起草到生效至少三年”不是同一种时长，不能自动判成矛盾。年轻、高职位是企划选择；只要明确履历没有互相挤占，不按现实简历模板强行改老。

台账的“540 年年差”只是年份差，不是精确周岁。三位彼方人物不拿主世界历法算年龄。

## 六、明确不应该当作矛盾的组合

| 组合 | 为什么可以共存 |
|---|---|
| 古风／现代／未来视觉元素 | 是作者的表现风格，不自动构成实际设备或现实年代的断言 |
| 封建政体使用新奇器物 | 封建描述土地、庇护、效忠等社会关系，不是科技禁令；奥嫩堡已经写明邻国器件会流入。定义参考 [4](https://www.britannica.com/dictionary/feudalism) |
| 共和国对外干涉与扩张 | 国体与对外政策不是同一变量；伊鲁尼利亚文本本来就有这种内外反差 |
| 卡法里扬的配给与私人寡头并存 | 资源控制、军事供给与私有财富可以同时存在；文本没有声称所有产业都纯粹自由市场或全数公有 |
| 铁枢的中央指令与州级讨论 | 不同层级权限可以并存；可补组织图，但现文字没有写州代表拥有最高无条件主权 |
| 同国保守派、改革者、共和派 | 是政治立场差异，不是国家已经同时完成三种互斥政体 |
| 理性主义者在神权国 | 她质疑经文推理，教廷劝她讲启示，是机构内的张力，不需要把她移出国家 |
| 工业科学与个人魔法 | 五位明确能力者均有对象、地域或耗神限制；个体异常不等于所有社会能工业化制造同样的术法 |
| 艾拉反优化与神乐坂研究改造 | 一方担忧社会压力，一方强调知情同意，是同一高科技社会内的伦理争论 |
| 殖民压迫下出现夜学与抵抗 | 保护国的统治者不等于全体居民的政治立场；杜芷的共和诉求不是当前国家已经改制 |
| 外来书带来现实思想家署名 | 沈青禾、杜芷、东方悦有明确许可和书本线索，不等于现实人物已经在主世界生活 |
| 顾月、燕归云、蕾奥妮用彼方历法 | 有意区别世界线；“另一世界”不是漏登记的主世界国家，不应加到主地图 |
