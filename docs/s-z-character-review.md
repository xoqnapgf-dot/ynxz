## 2. 核心修订

### 权力与关系

1. **科鲁鲁**：原稿同时让索菲在位亲政、叶卡捷琳娜掌现任摄政权，并将同批改革归给二人。修订保留索菲515年生、536年登基；叶卡捷琳娜改为508年生（年差32）、先王遗孀及前摄政，王位交接结束后没有自行发布国政命令的权力。仍有宫廷人脉与专制倾向，不改成开明女王的同义角色。**取消“王太后”称谓，不额外设母女、继母女、姐妹或孩子。**摄政与寡居是原有设定，不新增先王死因或另立君主。
2. **布图里亚**：埃莉诺·温莎十五岁时颁宪，对应527年；克莱门特改做修宪事务，不再呈现为首次制宪。她可以整理与推动意见，不能自己立法。地点志同步现行宪法和执行争议。
3. **铁枢**：叶卡捷琳娜·朱加什维利仍为515年生的计划委员会主任，掌计划部门而非被写成整个国家唯一统治者；建国以来的工业化并非她一个人的履历。保留追责扩大化、个人宣传与信息失真的问题，不替角色道德净化。林曼云的实业调度、秦望舒的州级讨论可与中央计划分层并存。
4. **伊鲁尼利亚**：舒彤仍为515年生，与舒和仍是双胞胎。党领袖不等于政府首脑；福利主张不等于全部已经实施。真凛是议员，池希是受托斡旋者，不替后者凭空增加表决权。两名资本角色不再只有通用银行核账：一人侧重放贷收益与资本份额，另一人侧重商家联合和扩大经营。
5. **其他年轻角色的职责**：艾娃改起草助理而非独当各邦外交，塞拉菲娜·瓦洛尔改骑士团小队长；薇克斯是会社受邀讲师而非学院强制任命的权威教职。其他职位不会仅因年轻就一律降职，限定它们实际管得到的范围。

### 经历、家庭与现代社会

- **玛格丽特·齐格勒**：删除与经验主义·班克斯重复的“母亲整理手稿／档案馆长大／前往同四地采样”整条经历。只保留并展开几何与逻辑讲席，年龄由年差34改26；两人仍是不同人物，没有新加亲缘。
- **尤朵拉**：20岁的首次牵头者；过去参与过合作社，不再是已经独立办过三轮、留下多处成功社区的资深创办人。
- **海德维希**：删除孤立的“两个孩子”及香灰化验、替人治伤支线，没有另编婚姻、监护或医学资质来兜住旧稿。25岁的教员围绕意识与物质条件展开。
- **露易丝**：29岁的已婚伯爵夫人仍合理；婚姻属于原身份核心，保留，不补子女年龄。海外封地保留为未落图背景，不新增国家，也不擅指契莱西亚为奥嫩堡殖民地。
- **夏梦华**：站主确认现代社会后，改为二十出头的公共政策专业学生，参与产业与就业实习，既关心公共经济与关键基础设施，也支持市场和多种经营主体。学习、实习与真实政策决定权分开，不再是没有背景支撑的农业大邦粮产督导。现代轨道交通、网络和大学属于她的彼方社会，不升级主世界科技。该社会国名与精确纪年仍未设定；不默认为与顾月、燕归云、蕾奥妮同一时间线。

### 思潮与文风

- 形式主义回到构成、比例与形式评价，不等同“按规章绘工程图”；原教旨主义回到坚持经典根本教义，不只是校勘仔细。
- 唯心主义明确心灵根本地位的信念，不是许愿术；唯物主义不只剩秤重、化验；自然主义不只剩抄观察记录，也不否认故事世界已出现的异常现象。
- 相对主义区分框架相关的合理性判断与可核实的潮汐事实；虚无主义恢复对客观意义与价值根据的怀疑，不写成万能毁灭魔法或谨慎读书员。
- 新反动主义明确集中治权、反民主、迁离而非投票的倾向，保留谁约束掌权者的缺口；并非普通的依法外包服务。
- 最小政府主义限制中央与地方的政府职能，不误写成只反对中央集权的联邦主义；自由意志主义区分强迫欺诈与贫穷债务，不把全部有债契约一概视为强迫。
- 殖民主义保留非对等支配与自我辩解，不因测量准确、反对下属贪污就淡化其立场。
- 减少核账、列清单、先问一句、最后改正自己的通用模板。允许偏执、回避、冷淡、逐利与固执，不把每个人改写成同一种负责的好人。不照搬立绘台词，不新增诗化头衔或神话血缘。
- 既定四位能力者的能力字段**完全未变**：茜尔芙蕾娅、塞勒涅、塞拉菲娜六世、薇拉。没有为消除玄虚文风顺手抹掉站主已确认的魔法设定。

## 5. 本轮联网参考

以下资料用于概念边界，不拿现实制度强行替代架空国家。没有重做113个思潮的全部思想史考据，思潮释义数据本轮未改。

- 艺术形式主义重视形式、线条、色彩与构成，而非工程流程合规：[1](https://www.tate.org.uk/art/art-terms/f/formalism)。唯美主义重艺术自身的审美价值：[1](https://www.tate.org.uk/art/art-terms/a/aesthetic-movement)。
- 观念论有本体论与认识论用法，不能简化为主观愿望：[1](https://plato.stanford.edu/entries/idealism/)。物理主义讨论世界的物理性与心身关系，不只是实测技巧：[3](https://plato.stanford.edu/entries/physicalism/)。
- 自然主义的方法论与本体论部分需要区分：[1](https://plato.stanford.edu/entries/naturalism/)。相对主义须说明哪种判断相对于哪种框架：[1](https://plato.stanford.edu/entries/relativism/)。关于人生意义的虚无主义不等于爱好毁灭：[1](https://plato.stanford.edu/entries/life-meaning/)。
- 实用主义以可设想的实际差别澄清问题，重视探究过程，不是唯成功论：[5](https://plato.stanford.edu/archives/fall2020/entries/pragmatism/)。
- 原教旨运动强调根本教义与经典，不能仅以校勘认真代表：[2](https://www.britannica.com/summary/Christian-fundamentalism)。这里借用概念，不给帕尔哈南移植现实宗教。
- 自由意志主义与最小国家的边界：[1](https://plato.stanford.edu/entries/libertarianism/)。
- 新反动主义的公司化主权和退出政治，参考 Smith、Burrows 的研究，而不采用搜索中立场博客的当代人物推测：[1](https://journals.sagepub.com/doi/10.1177/0263276421999439)。
- 殖民主义包含对外政治支配及其正当化，不能缩成地图技术：[1](https://plato.stanford.edu/archives/sum2010/entries/colonialism/)。
- 社会主义市场经济官方制度表述包含公有制为主体、多种所有制经济共同发展与市场机制，不能缩成单一粮食指令计划：[3](https://www.gjxfj.gov.cn/gjxfj/fgwj/gwywj/webinfo/2020/05/1590610492193917.htm)。此来源用于核对官方主张，不作为其现实成效的独立评价；夏梦华的现代背景来自站主本轮确认。
