# 意拟小站 · IDEOLOGICAL HUMANS

> **当前唯一网站入口：[GitHub Pages](https://xoqnapgf-dot.github.io/ynxz/)**。当前发布开发分支`arena/4c4cfaac-ynxz`，不合并main。旧raw.githack固定提交链接不会跟随新提交更新；InfinityFree镜像不在本次发布范围内。

以意识形态（今后扩展为各领域的「思潮」）拟人化角色和原创架空世界 Pierteia 为核心，包含画廊、世界地图、地点志、CP乱炖与讨论区的静态展示站。纯 HTML/CSS/JS，**无构建、无依赖**，本地双击 `index.html` 即可运行，也可整体部署到任意静态托管（GitHub Pages 等）。

> **接手的 AI 请先读「十一、接手指南」**（工作流、怎么加内容、行文与设定禁忌、用户的沟通习惯）。

> 声明：本站为个人世界观 / 角色企划的展示与创作。意识形态相关内容仅作**拟人化演绎 + 中立科普性介绍**，不代表任何现实政治立场。

## 一、世界观 · Pierteia（主世界）
- **历法**：新历；当前时间线约 **新历 540 年**。只有年份时，540减出生年是年差而非精确周岁；彼方角色不强行换算。
- **地理**：两块大陆之间隔着一道海峡；常灵群岛附近撕开一道**细长、曲折不规则的时空裂缝**，通往其它世界线（例如顾月所在的、已崩毁的古代汉族王朝）。世界尺度比地球更大，故国家普遍体量可观。
- **科技水平参考**：整体约近代工业水平（铁路、蒸汽船、电报、钢铁与重工业；边区仍用前膛枪与骡马，示安/霁川偏古风农耕，奥嫩堡/卡斯奎尼亚偏封建）；璇玑联邦是全图最高，专业研究达到近未来生命工学，但实验前沿不等于全民普及，治疗与增强各有成熟度和门槛。写新人物、新地点时请按所在地区的水平取材。
- **安那其学院**：海峡小岛上的自由学园，无政府诸流的讲习所，各方默许的中立飞地。
- **特殊地点**：天神峰（高原孤峰·通天之柱，超自然力量浓、易出超能力者）、常灵群岛（"常有灵"之群岛、紧邻裂缝，超常之事多；原称常灵岛）、万知城（中立理性、英杰汇聚的城邦）。
- **世界观基准（2026-10 定，写作与检查都按这套读）**：
  - **发展不同步**：近代工业（铁路、蒸汽船、电报、钢铁）是多数社会的基础参考；璇玑的研究与精密器件高于一般水平，边区与山地可以仍停留在骡马、前膛枪的阶段。同一国之内，大城、专业部门与乡野也不必在同一水平。
  - **主权与底图**：地图的国家底图由生成器一次划定，属草图与旧勘界；现行疆界、海岸、地名与主权一律以地点志和地图标记为准，个别描述按勘察修订（如璇玑为湖群内陆、无出海口）。安那其学院、常灵群岛、天神峰不隶属任何一国，地图上的政区浅彩不改变这一点。
  - **个人异能与魔法**：各有对象、范围与代价，是极少数人的天赋或修行，不能当成可量产的工业技术，也不用来解释国家的常规武力；特殊地点（天神峰、常灵群岛）天然多些，别处也可能出现，持有者仍属极少数，与所在国的国力、科技无关。
  - **立绘的时代混搭**：属表现风格（见「七」第 0 条），不用于推断科技水平、官制或人物的实际职权。

## 平面 ⇄ 3D
- `map.html` 是代码绘制的平面地图，`globe.html` 是独立的 3D 地球页，两页顶部「平面 / 3D地球」互相切换，并通过网址里的 `place=` 带上当前地点（如 `globe.html?place=安那其学院`）。
- 平面地图的地点卡与 3D 页的地点卡同一套视觉（`js/place-ui.js`）。两边的地点卡都有「进入3D沙盘」：平面地图上点它会带 `scene=1` 跳到 3D 页，飞到该地点后直接打开沙盘。
- 无独立坐标的下级地点（法洛塔、汐见町等）沿 `parent` 定位到所属地区，不编造地图点。
- v13—v22 的旧球体草稿（`drafts/pierteia-globe`，含八景实现、研究记录与约 160 张旧截图）已在 v23 删除，需要时可从 Git 历史查看。

## 四、功能特性
- **主题配色封面**：每个意识形态一套 `accent + accent2 + 唯一 SVG 纹样(motif)`，封面为**内联 data-URI SVG**（`designIdeologyCover` 生成，113 个 motif 各不相同，不依赖素材图）。日间模式另生成一张纸面版（同构图，浅纸底 + 压暗的主色墨线，`designIdeologyCover(ideo, false, true)`），卡片里两张图按 `data-theme` 切换，避免浅色页面上出现一块块深色卡。
- **人物介绍 + 基础信息**：角色名下方、简介上方；衬线正文 + 分隔线，无板块标题。
- **历史版本 + 「站主说」**：版本查看器右侧显示该图批注（仅填了才显示）。
- **地点志**：角色"属地/身份"里的地名可点击 → 弹出纸张风格的地点卡（与地图页同一套视觉）：种类、所属层级、正文、下辖地点、以此为属地的相关角色，并可直接「在地图上查看 / 3D地球」。弹层打开时会锁住背后的页面（`position:fixed` 记住滚动位置，关闭后还原），手指碰到遮罩不会滑动背景，避免 iOS 上滑动「跑」到背景人设页。
- **世界地图**：见下方「平面地图（v22）」。默认只显示已设定的国家与特殊地点的地名；地图生成器划出、尚无设定的地区可在「图层」里打开「未设定地区」。下级地点（法洛塔、艾迪州等）没有独立坐标，只在所属国家的地点卡里列为「下辖地点」，不编造地图点。
- **响应式**：移动端适配（网格、工具栏、弹窗、地图手势等）。

## 六、技术实现要点
- **主题色传递**：详情页把 `--ca/--ca2` 设在 `#galDetailPage`；body 级弹窗（版本查看器、地点志）不继承，代码里手动 `getComputedStyle` 复制过去。

## 七、内容规范（新增内容须遵守；旧条目仅供参考）
0. **分类名**：画廊里原来的「意识形态」标签已改叫「思潮」（以后会加入道家、名家、阴阳家等非政治类思想流派）；站名「意拟小站 · Ideological Humans」与首页的声明文字是站主原话，保持不动。
0. **立绘时代混搭（站主确认）**：人物图像可以古今未来混用。服装、建筑与象征性道具不直接证明科技水平、政治体制或实际职位；一致性检查以人设、地点志及已确认的文字设定为准，不要求全站统一现实年代。
0. **行文去 AI 腔**：少用「如今 / 在她看来 / 不是……而是…… / 并不…… / 一件件一条条 / 有人说……也有人说」这类句式，少写总结式的格言收尾；多写具体的事，句子短一点，别每句都以「她」开头。
1. **架空世界**：人设（`bio` / `info`）和地点志里的国家、地名、时代、政权、官制、宗教机构、现实人物，一律不得与现实世界重叠（不写苏联、美国、古希腊、衙门，也不点现实思想家的名字），一律用架空译名或不点名的说法。**现实人名、学说、历史只允许出现在「意识形态释义」里**；人设里除站主指定的少数特殊人物（如沈青禾、杜芷与东方悦读到的外来册子）外，都不要出现。
2. 意识形态释义：中立、考据、主流，**两段用 `\n\n` 分隔**，不掺角色口号。
3. 角色 `bio`：**不 OOC、不擅自加情节**、**分段**、**别滥用破折号**。**不要看图说话**：别逐件描写立绘里的道具、服饰，也别照搬立绘上的台词/标语，人设从意识形态与角色气质出发。年龄不必教条回避：「老学者」「比某某小两个月」这类自然口语表述没问题；只是别凭空写与立绘、"出生日期"矛盾的具体岁数，具体日期仍以"出生日期"一栏为准。
4. 地点 `desc`：**只写地方本身，绝不点名角色**（角色↔地点靠"属地"关联）。
5. **配色、外貌年龄一律以立绘为准**（主色看画面，别把点缀当主色；脸多大就多大）。
6. **角色归属与地点层级**：写新角色时，优先安置到已有的国家、城邦或其他已设定的大地区；不要为了给角色找住处而随意新建国家或大区。若需要更具体的居所、工作地、街区、矿区、乡社、村镇或设施，可以在既有大地区之下新建二级 / 小地点，并用 `LOCATION_DATA` 的 `parent` 写清隶属关系。只有确有设定需要时才考虑新增国家或独立大区，并先向站主确认。角色的 `属地` 应使用地点志已有的正式名称（或已配置的 `LOCATION_ALIAS`）；小地点不必自动添加地图标记，除非用户要求或地图表达确有必要。所有新增地点仍须符合世界观尺度、主世界 / 异世界边界与所在地科技水平。不参考 Azgaar 原始地图里的人口、面积数字，一律以本站比例尺（`KM_PER_UNIT`）为准。

## 十一、接手指南（给其他 AI / 协作者）
站主是中文用户，项目目前**以补写人设、世界观文本为主**，其余功能暂时够用。

### 1. 工作流（站主的固定约定）
1. 在开发分支上改，**每次改完都提 PR 并合并进 `main`**（GitHub Pages 从 `main` 部署）；不要直接往 `main` 硬推。
2. 合并后用中文回复一份简短总结，并**把预览链接各占一行、前后空行、后面不再附别的内容**：
   `https://xoqnapgf-dot.github.io/ynxz/`、`.../gallery.html`、`.../map.html`。
3. 改了 `css/js` 必须升 `?v=` 版本号（**同一文件在所有 HTML 页里的版本号必须一致**），并同步更新本 README 的「当前版本指针」与受影响的表格 / 规模数字。
4. 站点部署在 `/ynxz/` 子路径，所有资源用**相对路径**。

### 2. 常见任务怎么做
- **给角色写人设**：先看大图 `素材/角色大图/*`（配色、外貌、年龄以立绘为准，但不要看图说话），在 `gallery-data.js` 该角色下加 `bio`（分段，`\n\n` 字面分隔）与 `info` 数组；每项使用 `{k:'字段名',v:'内容'}`，字段顺序为身份、出生日期、能力（可选）、属地。出生日期用「新历N年」，当前约新历 540 年，按外貌估龄。`属地` 必须写**地点志里已有的地名**才会变成可点击链接，`身份` 里可以写简称（见 `LOCATION_ALIAS`）。
- **新增或补写地点 / 国家**：先复用已有国家、城邦或其他大地区；给角色安排归属时，不要为方便而新建国家 / 独立大区。若人设需要更具体的居所或工作地，可以在已有大地区下新建乡社、城镇、街区、矿区、工作场所等二级 / 小地点，并在 `locations-data.js` 的 `LOCATION_DATA` 加 `{名称:{desc,kind,parent}}`，用 `parent` 指向已有地点。新简称写进 `LOCATION_ALIAS`；角色 `属地` 使用地点志已有正式名称或其别名。地点 `desc` **只写地方，不点名角色**；小地点默认不单独添加地图标记，除非用户要求或地图表达确有必要。只有确有世界观需要时才新增国家 / 独立大区，并先向站主确认。考虑世界尺度（大陆是现实的 4 倍多）与所在地科技水平（见第一节「科技水平参考」）。
- **新增思潮（意识形态 / 学派）**：在 `gallery-data.js` 加一个条目（`id,name,initial,desc,theme:{accent,accent2,hi?,frame?,dust?,motif}`），并在 `gallery.js` 的 `motifDeco` 里加**唯一**的 `motif` 分支（`MOTIF_SCALE` 可调大小，纹样要居中、线条别过细）。释义中立、考据、两段。
- **改图标 / 封面**：封面是内联 SVG，全部由 `gallery.js` 生成，不需要图片素材。

### 3. 行文与设定禁忌（站主反复强调过）
- **去 AI 腔**：见「七、内容规范」第 0 条。简介要具体、句子短，别每句都「她」，别格言式收尾。
- **旧 AI 内容与格式**：仓库中历次补写的角色、地点条目可能没有完全遵守格式或设定规则；已存在不等于已确认合规，也不要把它们当作规范样板。新增或改写时以本 README 的明确规则和站主后续确认优先；发现旧条目与规则冲突时先指出具体差异，未经要求不要批量改写既有设定。`bio` 用 `\n\n` 分段，`info` 按「身份 → 出生日期 → 能力（可选）→ 属地」排列；提交前逐项检查格式与地点隶属。
- **不看图说话**，不照搬立绘上的台词；不 OOC、不擅自加情节；年龄不要和立绘、「出生日期」矛盾。
- **事实要查**：涉及现实思想、学说、历史的内容必须联网搜索核对，不要凭记忆；不确定就说不确定。
- 架空世界：人设和地点志里不得出现现实的国名、地名、朝代、时代、人物（站主指定的特殊人物除外）；现实人名与历史只放在意识形态释义里。
- 引号用全角「」；字符串里不要出现 ASCII 单引号，否则会截断 JS 字符串。

### 4. 沟通习惯与已知坑

- 每处的地形、材质、时段、天气各不相同：如安那其学院是依山一层层修上去的台地，山顶是改作大讲堂和书库的旧城堡，城堡正面、城门和广场地面都有Ⓐ；万知城是环城墙里的书城，中央广场立着铜浑仪，图书馆有六柱门廊和带肋的铜绿圆顶；法洛塔是夜里的山坡港口与灯串、汐见町是退潮后的滩涂与细雨、天神峰是黎明的孤峰冰川与云海、南境工矿区是雪夜的井架与探照灯、常灵群岛是蓝调时分的雾、密林与发光裂缝。配方里的说明文字（`note`）只写地方，不点名角色。
- 引擎（`engine.js`）：程序化地形 + 平台 / 道路 / 河道整形，按地形自动着色；房屋、桥梁、船、工业设施等由 `props.js` 组合，合并成少量网格；树木、人、牲畜、石头、草用实例化；材质在着色器里程序生成（砖、瓦、石、木、金属、玻璃……），夜里窗户会亮。光照为太阳阴影 + 半球光 + 天空环境贴图；后期为 GTAO 环境光遮蔽、泛光、移轴景深与调色。天气（雨、雪、花瓣、落叶、萤火、雾层、积云、闪电、彩虹、极光 / 裂缝光幕、烟、探照灯、飞鸟）在 `fx.js`，可用「天气与动态」开关。积云挡在镜头和主体之间时会自动淡出；有雷雨云时闪电从云底劈下。
- 手机或低性能设备（`coarse`）自动减少实例数量与光源；系统开启「减少动态效果」时不播放镜头飞行。
- 画质分三档（`engine.js` 的 `quality`）：电脑默认 high（PCF 软阴影每帧更新、GTAO、4×MSAA、移轴 18 次采样、分辨率上限 2）；手机默认 mid（阴影图 1536、每 4 帧更新一次、不做 GTAO、2×MSAA、移轴 8 次采样、分辨率上限 1.25）；low 关掉移轴，阴影只画一次，泛光只在夜景保留。`app.js` 按相邻两次实际绘制的间隔（不是 JS 耗时——手机多半卡在 GPU 上，JS 耗时看不出来）统计帧率，连续约 45 帧平均低于约 32 帧/秒就调用 `dio.degrade()` 降一档；降到 low 后再把沙盘渲染分辨率每次降 0.25，最低 0.75。不在沙盘时同样的判断用来降低星球的分辨率。调试可用 `__globe.degrade()` 手动降档，`__globe.stats().diorama` 里能看到当前 `quality` 与 `pr`。
- 写新配方：坐标 +x 东、+z 南；视角 `az=0` 是从南往北看，`az=90` 从东往西看。没有水的地点写 `water:false`。
