# 意拟小站 · IDEOLOGICAL HUMANS

以意识形态拟人化角色和原创架空世界 Pierteia 为核心，包含画廊、世界地图、地点志、CP乱炖与讨论区的静态展示站。纯 HTML/CSS/JS，**无构建、无依赖**，本地双击 `index.html` 即可运行，也可整体部署到任意静态托管（GitHub Pages 等）。

> 声明：本站为个人世界观 / 角色企划的展示与创作。意识形态相关内容仅作**拟人化演绎 + 中立科普性介绍**，不代表任何现实政治立场。

## 一、世界观 · Pierteia（主世界）
- **历法**：新历；当前时间线约 **新历 540 年**。
- **地理**：两块大陆之间隔着一道海峡；常灵岛附近撕开一道**细长、曲折不规则的时空裂缝**，通往其它世界线（例如顾月所在的、已崩毁的古代汉族王朝）。世界尺度比地球更大，故国家普遍体量可观。
- **安那其学院**：海峡小岛上的自由学园，无政府诸流的讲习所，各方默许的中立飞地。
- **特殊地点**：天神峰（高原孤峰·通天之柱）、常灵岛（"常有灵"之岛、紧邻裂缝）、万知城（中立理性、英杰汇聚的城邦）。

## 四、功能特性
- **主题配色封面**：每个意识形态一套 `accent + accent2 + 唯一 SVG 纹样(motif)`，封面为**内联 data-URI SVG**（`designIdeologyCover` 生成，113 个 motif 各不相同，不依赖素材图）。
- **人物介绍 + 基础信息**：角色名下方、简介上方；衬线正文 + 分隔线，无板块标题。
- **历史版本 + 「站主说」**：版本查看器右侧显示该图批注（仅填了才显示）。
- **地点志**：角色"属地/身份"里的地名可点击 → 弹卡片，沿 `parent` 逐级上溯。
- **世界地图**：单指拖 + 双指捏合缩放、地形/国家底图切换、国家(红点)/特殊地点(紫菱形)标记、常灵岛附近细长不规则的发光**时空裂缝**、"点一下读坐标"放置工具。下级行政区、城市与小地点暂不全量标注，避免默认标注层过密；后续如有需要，优先做独立开关或随缩放分级显示。
- **响应式**：移动端适配（网格、工具栏、弹窗、地图手势等）。

## 六、技术实现要点
- **主题色传递**：详情页把 `--ca/--ca2` 设在 `#galDetailPage`；body 级弹窗（版本查看器、地点志）不继承，代码里手动 `getComputedStyle` 复制过去。
- **配色来源（v65 起）**：一律**看立绘定色**后手写进 `theme.accent/accent2`（主色按画面面积占比判断，别把点缀当主色）；旧的「运行时像素取色兜底」已移除（32×48 采样过粗、分不清主色/点缀、取色死板）。缺色时补数据，不补算法。
- **纹样/封面**：`motifDeco(motif,col)` 每个分支返回一个居中 SVG `<g>`；新增意识形态须加**唯一** motif 分支。
- **地图坐标**：标记用整图归一化 `x,y`(0–1)；底图 3000×935；`KM_PER_UNIT≈21.3`（比例尺，待校准）。
- **缓存击穿**：所有 `css/js` 引用带 `?v=N`，每次改动**必须升版本号**，否则线上/手机读到旧文件。

## 七、内容规范（编辑时务必遵守）
1. **架空世界**：正文不出现现实国家/专有名词（苏联、美国、衙门…一律不写）。
2. 意识形态释义：中立、考据、主流，**两段用 `\n\n` 分隔**，不掺角色口号。
3. 角色 `bio`：**不 OOC、不擅自加情节、不写年龄**（年龄交给"出生日期"）、**分段**、**别滥用破折号**。
4. 地点 `desc`：**只写地方本身，绝不点名角色**（角色↔地点靠"属地"关联）。
5. **配色、年龄一律以立绘为准**（主色看画面，别把点缀当主色；脸多大就多大）。
6. **归属只并入"已写过介绍的国家"**；没有合适归属先问，不擅自给空白国现编。

## 八、运行与部署
- **本地**：双击 `index.html`（`file://`）即可，无需服务器/构建。
- **静态托管（GitHub Pages 等）**：整站目录直接部署。
- **图片**：意识形态封面是内联 SVG，任何环境都显示；角色大图/预览图依赖 `素材/`。仓库内 `素材/` 为**网页压缩版**（原图另存），使 Pages 也能加载图片；旧批量压缩脚本已移除，避免误覆盖源图。
- **在线镜像**：InfinityFree `ynxz.wuaze.com`（含全量素材）。
- **协作约定**：改动走**分支**、给出**分支 raw 预览链接**、**不主动合并 main**、每次改动**同步更新本 README**。
- **raw 预览链接格式（必须照用）**：用 HTMLPreview 渲染 GitHub 分支上的页面：`https://htmlpreview.github.io/?https://raw.githubusercontent.com/dacl666-code/ynxz/<branch>/<page>.html`。交付时至少给首页及本次改动页（如 `index.html`、`map.html`、`gallery.html`）的可点击预览链接。单独的 `raw.githubusercontent.com` 文件地址只是源码，不是预览；Arena/E2B Live Preview、`raw.githack.com` 或 localhost 链接也不能替代本项目约定的 raw 预览。

## 九、维护备忘
- 编辑 `gallery-data.js` 等时：文件里字符串内的换行是**字面 `\n\n`**；正文里的引号请用全角 `「」`（ASCII 单引号会截断 JS 字符串）。
- 数据/脚本改动后：`node --check` 语法自检 + 升 `?v=` + 浏览器实测渲染。
- 本站无需安装构建依赖；临时检查工具用完清掉 `node_modules`、`.npmcache`，勿进仓库（已有 `.gitignore` 兜底）。
- 地图卡片介绍单一来源：地点志已收录的地点一律读 `locations-data.js`；`map-data.js` 只保留地点志**没有**的地点的 desc（当前为空）。
- 当前版本指针：`style.css v23`、`gallery.css v47`、`gallery.js v69`、`gallery-data.js v81`、`versions-data.js v5`、`locations-data.js v14`、`map-data.js v23`、`cp.js v7`、`search.js v4`、`main.js v1`。**同一文件在所有页面的 `?v=` 指针必须一致**（曾出现 search.html 把 gallery-data 停在 v12，导致搜索页读旧缓存）。
