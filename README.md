# 意拟小站 · IDEOLOGICAL HUMANS

以意识形态（今后扩展为各领域的「思潮」）拟人化角色和原创架空世界 Pierteia 为核心，包含画廊、世界地图、地点志、CP乱炖与讨论区的静态展示站。纯 HTML/CSS/JS，**无构建、无依赖**，本地双击 `index.html` 即可运行，也可整体部署到任意静态托管（GitHub Pages 等）。

> **接手的 AI 请先读「十一、接手指南」**（工作流、怎么加内容、行文与设定禁忌、用户的沟通习惯）。

> 声明：本站为个人世界观 / 角色企划的展示与创作。意识形态相关内容仅作**拟人化演绎 + 中立科普性介绍**，不代表任何现实政治立场。

## 一、世界观 · Pierteia（主世界）
- **历法**：新历；当前时间线约 **新历 540 年**。
- **地理**：两块大陆之间隔着一道海峡；常灵群岛附近撕开一道**细长、曲折不规则的时空裂缝**，通往其它世界线（例如顾月所在的、已崩毁的古代汉族王朝）。世界尺度比地球更大，故国家普遍体量可观。
- **科技水平参考**：整体约近代工业水平（铁路、蒸汽船、电报、钢铁与重工业；边区仍用前膛枪与骡马，示安/霁川偏古风农耕，奥嫩堡/卡斯奎尼亚偏封建）；璇玑联邦是全图最高，达到近未来生命工学。写新人物、新地点时请按所在地区的水平取材。
- **安那其学院**：海峡小岛上的自由学园，无政府诸流的讲习所，各方默许的中立飞地。
- **特殊地点**：天神峰（高原孤峰·通天之柱，超自然力量浓、易出超能力者）、常灵群岛（"常有灵"之群岛、紧邻裂缝，超常之事多；原称常灵岛）、万知城（中立理性、英杰汇聚的城邦）。

## 四、功能特性
- **主题配色封面**：每个意识形态一套 `accent + accent2 + 唯一 SVG 纹样(motif)`，封面为**内联 data-URI SVG**（`designIdeologyCover` 生成，113 个 motif 各不相同，不依赖素材图）。
- **人物介绍 + 基础信息**：角色名下方、简介上方；衬线正文 + 分隔线，无板块标题。
- **历史版本 + 「站主说」**：版本查看器右侧显示该图批注（仅填了才显示）。
- **地点志**：角色"属地/身份"里的地名可点击 → 弹卡片，沿 `parent` 逐级上溯。
- **世界地图**：默认只显示「已设定」的国家与特殊地点（写进地点志、有角色归属的才算存在），其余是地图生成器自动划定的占位，可用左上「显示未设定地区」临时显示，点开会标明「尚未登场」。单指拖 + 双指捏合缩放、地形/国家底图切换、国家(红点)/特殊地点(紫菱形)标记、常灵岛附近细长不规则的发光**时空裂缝**、"点一下读坐标"放置工具。下级行政区、城市与小地点暂不全量标注，避免默认标注层过密；后续如有需要，优先做独立开关或随缩放分级显示。
- **响应式**：移动端适配（网格、工具栏、弹窗、地图手势等）。

## 六、技术实现要点
- **主题色传递**：详情页把 `--ca/--ca2` 设在 `#galDetailPage`；body 级弹窗（版本查看器、地点志）不继承，代码里手动 `getComputedStyle` 复制过去。
- **配色来源（v65 起）**：一律**看立绘定色**后手写进 `theme.accent/accent2`（主色按画面面积占比判断，别把点缀当主色）；旧的「运行时像素取色兜底」已移除（32×48 采样过粗、分不清主色/点缀、取色死板）。缺色时补数据，不补算法。
- **纹样/封面**：`motifDeco(motif,col)` 每个分支返回一个居中 SVG `<g>`；新增意识形态须加**唯一** motif 分支。
- **地图坐标**：标记用整图归一化 `x,y`(0–1)；底图 3000×935；`KM_PER_UNIT = 21.3`（比例尺，站主确认可用）：整图约 6.4 万 km × 2.0 万 km，陆地面积约为地球陆地的 4 倍多（总面积约地球的 2.5 倍）。**不要参考 Azgaar 原始数据里的人口、面积数字**，一律按本站比例尺理解。
- **缓存击穿**：所有 `css/js` 引用带 `?v=N`，每次改动**必须升版本号**，否则线上/手机读到旧文件。

## 七、内容规范（编辑时的参考，不必死板套用）
0. **分类名**：画廊里原来的「意识形态」标签已改叫「思潮」（以后会加入道家、名家、阴阳家等非政治类思想流派）；站名「意拟小站 · Ideological Humans」与首页的声明文字是站主原话，保持不动。
0. **行文去 AI 腔**：少用「如今 / 在她看来 / 不是……而是…… / 并不…… / 一件件一条条 / 有人说……也有人说」这类句式，少写总结式的格言收尾；多写具体的事，句子短一点，别每句都以「她」开头。
1. **架空世界**：国家、地名、政权、官制等设定层面的词用架空译名，不直接套现实国家与朝代（苏联、美国、衙门之类尽量别写）。**人名、意识形态名、思想流派名属于本站题材本身，可以正常出现**，不必刻意回避。
2. 意识形态释义：中立、考据、主流，**两段用 `\n\n` 分隔**，不掺角色口号。
3. 角色 `bio`：**不 OOC、不擅自加情节**、**分段**、**别滥用破折号**。**不要看图说话**：别逐件描写立绘里的道具、服饰，也别照搬立绘上的台词/标语，人设从意识形态与角色气质出发。年龄不必教条回避：「老学者」「比某某小两个月」这类自然口语表述没问题；只是别凭空写与立绘、"出生日期"矛盾的具体岁数，具体日期仍以"出生日期"一栏为准。
4. 地点 `desc`：**只写地方本身，绝不点名角色**（角色↔地点靠"属地"关联）。
5. **配色、外貌年龄一律以立绘为准**（主色看画面，别把点缀当主色；脸多大就多大）。
6. **归属**：优先并入已写过介绍的国家；也可以在地图上挑一个占位国补写（或新增国家 / 地点），但须符合世界观尺度与该地区科技水平，在地点志登记后才会在地图上亮标记。不参考 Azgaar 原始地图里的人口、面积数字，一律以本站比例尺（`KM_PER_UNIT`）为准。

## 八、运行与部署
- **本地**：双击 `index.html`（`file://`）即可，无需服务器/构建。
- **静态托管（GitHub Pages 等）**：整站目录直接部署。

## 十一、接手指南（给其他 AI / 协作者）
站主是中文用户，项目目前**以补写人设、世界观文本为主**，其余功能暂时够用。

### 1. 工作流（站主的固定约定）
1. 在开发分支上改，**每次改完都提 PR 并合并进 `main`**（GitHub Pages 从 `main` 部署）；不要直接往 `main` 硬推。
2. 合并后用中文回复一份简短总结，并**把预览链接各占一行、前后空行、后面不再附别的内容**：
   `https://xoqnapgf-dot.github.io/ynxz/`、`.../gallery.html`、`.../map.html`。
3. 改了 `css/js` 必须升 `?v=` 版本号（**同一文件在所有 HTML 页里的版本号必须一致**），并同步更新本 README 的「当前版本指针」与受影响的表格 / 规模数字。
4. 站点部署在 `/ynxz/` 子路径，所有资源用**相对路径**。

### 2. 常见任务怎么做
- **给角色写人设**：先看大图 `素材/角色大图/*`（配色、外貌、年龄以立绘为准，但不要看图说话），在 `gallery-data.js` 该角色下加 `bio`（分段，`\n\n` 字面分隔）与 `info:[{k:'身份'},{k:'出生日期'},{k:'能力'(可选)},{k:'属地'}]`。出生日期用「新历N年」，当前约新历 540 年，按外貌估龄。`属地` 必须写**地点志里已有的地名**才会变成可点击链接，`身份` 里可以写简称（见 `LOCATION_ALIAS`）。
- **新增或补写地点 / 国家**：在 `locations-data.js` 的 `LOCATION_DATA` 加 `{名称:{desc,kind,parent?}}`；简称写进 `LOCATION_ALIAS`；国家在 `map-data.js` 里已有占位标记（只有地点志里有的才会亮）。地点 `desc` **只写地方，不点名角色**；考虑世界尺度（大陆是现实的 4 倍多）与所在地区科技水平（见第一节「科技水平参考」）。
- **新增思潮（意识形态 / 学派）**：在 `gallery-data.js` 加一个条目（`id,name,initial,desc,theme:{accent,accent2,hi?,frame?,dust?,motif}`），并在 `gallery.js` 的 `motifDeco` 里加**唯一**的 `motif` 分支（`MOTIF_SCALE` 可调大小，纹样要居中、线条别过细）。释义中立、考据、两段。
- **改图标 / 封面**：封面是内联 SVG，全部由 `gallery.js` 生成，不需要图片素材。

### 3. 行文与设定禁忌（站主反复强调过）
- **去 AI 腔**：见「七、内容规范」第 0 条。简介要具体、句子短，别每句都「她」，别格言式收尾。
- **不看图说话**，不照搬立绘上的台词；不 OOC、不擅自加情节；年龄不要和立绘、「出生日期」矛盾。
- **事实要查**：涉及现实思想、学说、历史的内容必须联网搜索核对，不要凭记忆；不确定就说不确定。
- 架空世界不直接套现实国名 / 朝代（人名、思潮名可以）。
- 引号用全角「」；字符串里不要出现 ASCII 单引号，否则会截断 JS 字符串。

### 4. 沟通习惯与已知坑
- 站主常用**语音输入**，会有同音错字：如「天旋风 / 天神风」= 天神峰，「长岭岛 / 长宁群岛」= 常灵群岛，「艾拉费血」= 艾拉·费雪，「乙星球」意指另一个世界 / 星球。拿不准就按上下文判断，必要时再确认。
- 站主不喜欢"凭印象说确定的话"：没把握要明说，并去搜索核实；批量任务要**全部过一遍**，不要抽样。
- 额度有限，尽量一次做完、少反复；不要重复展示大段内容。
