# 下一轮三维样板的美术标准

日期：2026-10-15。状态：**候选工作标准，尚未通过新画面验证，不是用户已经认可的最终画风。**

**v12执行状态：** v11的尺度人物、庭院机位、参考材质和摄影IBL保留；v12进一步修改北坡露头、树冠、屋瓦、连廊及采光窗，并经过近景返工。仍未完成全部美术验收，尤其是山体大轮廓、地被、全局间接光和其他地区，见[目视记录](research/v12-visual-review.md)。

依据与查看边界：[research/README.md](research/README.md)。这是为当前项目作出的设计决定，不是某个工具的默认模板。

## 要做成什么

有真实尺度、可信施工和生活痕迹的山地学园。建筑要像能进入的地方，而非俯视沙盘上的装饰件。

继续保留开放环形总体关系、依山的分散楼群、低入口圈A，以及原有正式地图。不要做斗兽场、整圈筒楼、高圆台或双塔。不同国家也不能被同一套学园构件替代。

**不采用：**低多边形玩具风、到处发光的奇观、统一噪声做旧、重景深微缩效果，或用二维图像冒充可绕看的三维空间。

## 先锁尺度与主次

- 全部局部资产以米为制作尺度；导入场景的缩放集中定义，不让门、树、人、家具各自猜比例。
- 1.70米参考假人、门、桌椅与栏杆在同一测试空间出现。假人用于校准，不改正式角色设定。当前0.40米占位人不能继续充当成人尺度参照。
- 总览负责说明校园布局；人眼视角负责说明可进入的空间；细节视角负责验证材料。这三种任务不能都由高机位完成。
- 人眼视角以选定的**可站立表面**上方约1.6–1.7米设置。平台、楼板与地形分开处理，不一律加在地形高度上。
- 主体立面不能被连廊、栏杆或最近的树冠挡住大半；宁可移动取景点或减弱配角，不靠透明化主体作弊。

## 建筑语言

主体：安静的灰泥面和石基；支撑：有明确受力关系的木构；点缀：屋面金属与少量入口标识。不是“每一面都同样精细、同样醒目”。

- 建立大体量、开间和构件三级尺度。窗台、雨槽、瓦边是小构件，不能变成轮廓最抢眼的积木。
- 保留立面空白和主入口；图书馆至少有不同功能的开间，不能把每格都做成满窗书本的橱窗。
- 木柱/梁/栏杆的截面和接头分别设计；不把同一根圆柱缩放成所有东西。
- 门框、窗框、石材和金属折边各自有符合材料的收口与倒角，禁止所有部件统一“圆角化”。
- 屋瓦先依据实物确定长度、宽度、有效搭接和边缘厚度，再决定几何细分。不是用随机明暗区分一格格瓦。
- 基础、踏步、地面、排水连续；不能用大块挡墙把所有落地问题遮住。

## 材质要回答的问题

每套材料必须有来源、许可、覆盖物理尺寸、颜色空间、通道语义和近景用途。模型库的开源许可不能代替贴图与模型自己的授权。

| 材料 | 应该能读出的特征 | 不再接受的替代物 |
|---|---|---|
| 灰泥 | 柔和漫反射、细小颗粒、局部受潮差异 | 灰黄纯色乘一层大噪声 |
| 石基/铺地 | 石块与缝的真实尺寸、断口和受压边缘 | 整块圆滑体积表面印方格 |
| 木材 | 沿构件走向的纹理、端面和切割边不同 | 每条构件都贴同一旋涡或发亮棕色 |
| 屋面 | 陶瓦/石板/金属分别成立，搭接与檐口有厚度依据 | 所有屋顶只换一张颜色 |
| 玻璃 | 环境反射、开口深度、室内明暗层次 | 不透明蓝片，或为“通透”而统一降低透明度 |
| 地面 | 土、草、落叶、裸露路径有成因和过渡 | 满地撒等间距草点和白色碎石 |

- 带颜色的纹理是否还应乘棕色材质，要先在中性照明下验证，不能双重染色。
- 粗糙度先有大/中尺度差异，再加微观变化；不要靠更大的法线强度制造“高清”。
- 裸露导体和非金属表面分别处理。氧化/涂漆用材料覆盖逻辑，不把金属度随便设为0.2–0.7来调颜色。
- 影响轮廓和近景视差的构造交给几何/位移；微观起伏交给法线。先确定看什么，再分配几何与贴图预算。
- 下一样板至少有一组来源明确、尺寸可核对的真实PBR基线，与自制材质在同光照下比较。v11已加入MaterialX参考表面（不宣称扫描）及Poly Haven摄影HDR，逐资源记录见assets/study/。

## 照明与相机

先做一套稳定的中性日光基线，再建立正式氛围。这样能看出材质错误，而不是靠统一暖滤镜遮住它。

- 一套有方向依据的主光与环境光，固定曝光；相机绕行时不能为了让每一面都亮而偷偷移动局部主光。
- 阴影必须保留体积和可读暗部。AO只补接触与缝隙，不把画面整体染黑，不声称它等于GI。
- 样板比较用相同资产、相同机位和相同曝光；先测试GLB标准材质，再决定自定义shader覆盖。
- 渲染输出和显示色彩转换只做在正确位置；颜色贴图和法线/粗糙度等数据贴图区分处理。
- 默认不开强景深，不加色差或颗粒掩盖缺陷；静态画面未过关，暂不增加镜头飞行和额外粒子。

## 自然环境

先定义每个区域的湿度、风化和植物形态，再决定散布。不是随机数越多越自然。

- 近景树要有可信树皮、枝序、冠幅与透光，不以“每片叶都是几何”自证质量。
- 地被成簇，留出清晰路径与建筑基础；坡度、落水、人的踩踏决定裸露地面。
- 植被有主树、次树和背景树的任务区别，不统一同密度覆盖。
- 树根、岩石和草的接地要在斜侧视角复查。

## 工具的实际职责

- **Blender**：主要资产造型、尺度、UV、局部高模和烘焙，导出GLB。已有建模脚本不代表当前环境已跑通GPU Cycles；需要实际验证后才能报告已使用。
- **PBR/HDRI资源**：用于建立真实材质/照明基线，先核逐资产许可和可重分发范围。
- **Three标准/物理材质**：互动交付基线；CSM仅在确实需要自定义时验证引入。
- **参考glTF查看器**：区分导出问题和本项目运行时材质覆盖问题。
- **WebGPU/GI/路径追踪实验**：独立测试分辨率、稳定性和能力回退，不突然替换整张地图。不把“可以写代码”说成“已经跑通”。
- **生成式图片、绘画库、视频工具**：可以辅助参考或另有明确交付时使用；不代替可交互三维资产，不复制案例提示词或别人的整套外观。

## 下一样板的验收

范围：学院入口到阅读庭院的一小段，至少包含一个主体墙面、真实开口、屋檐、接坡铺地与一棵近景树。先做扎实，再推至八景。

技术检查与美术检查分别记录：

1. 无资源/着色器错误、单位与色彩空间正确、模型可环绕且没有露底，仅代表技术通过。
2. 同一模型的中景、人眼视角与斜侧材质近景都成立；普通分辨率就能区别石、木、灰泥与玻璃。
3. 去掉颜色与后期仍能读出主次体量；去掉装饰后主体不能塌成一排盒子。
4. 与本轮参考一起看：哪里学了尺度、哪里学了明暗、哪里仍未达到，写具体问题，不打自我感觉分。
5. 如果还像当前的玩具沙盘，则继续样板返工，不能凭测试日志或资产数量推广到全图。

仍以在线互动为主。用户未再要求前，不自主跑长时间4K图集。每轮研究、源文件和验证结果提交并推送到当前分支，回复给实际提交号；不合main、不自动部署。
